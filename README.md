# buildCapital — сервер

API заявок на материалы. Заказчик создаёт заявку по объекту, исполнитель отмечает выполнение, администратор ведёт пользователей, справочник и цены. Цены хранятся в заявке отдельно от справочника: изменение цены в справочнике не меняет уже созданные заявки.

Сервер на NestJS и PostgreSQL. Рядом лежит фронтенд в репозитории `buildCapital_front`.

Если по одному и тому же объекту в текущую неделю, с понедельника по воскресенье, приходит ещё одна заявка, она не создаёт новую карточку. Позиции добавляются в уже открытую заявку этой недели. В PDF сначала идёт исходный блок с первой датой и автором, ниже — такой же блок с датой, именем и новыми позициями. После дополнения администраторам и исполнителям снова уходит PDF. Неделя считается в часовом поясе `APP_TIMEZONE`, по умолчанию Екатеринбург.

## Роли

- **Администратор** — пользователи, справочник, цены, все заявки.
- **Исполнитель** — все заявки, отметка выполнения, цены. Свои заявки не создаёт.
- **Заказчик** — только свои заявки, без цен.

Администратор и исполнитель получают уведомления в приложении. Если подключён Telegram-бот, им же уходит новая заявка с PDF. В PDF нет цен и нет статуса выполнения.

## Что нужно заранее

- Node.js 20 или новее
- Docker, чтобы поднять PostgreSQL

## Запуск

Из этой папки:

```bash
docker compose up -d
cp .env.example .env
npm install
npx prisma generate
npm run db:setup
npm run start:dev
```

API будет на `http://localhost:3000`, префикс маршрутов — `/api`.

`npm run db:setup` применяет миграции и создаёт администратора:

| Роль | Email | Пароль |
| --- | --- | --- |
| Администратор | melnikovaleksey97@yandex.ru | 12345678 |

Повторный запуск сида обновляет пароль этого пользователя. Остальных пользователей он не удаляет.

## Переменные

Файл `.env` в git не попадает. Пример — `.env.example`.

- `DATABASE_URL` — строка подключения к Postgres. Локальная база называется `buildcapital`, пользователь и пароль тоже `buildcapital`
- `JWT_SECRET` — секрет подписи токена, на сервере замените значение из примера
- `PORT` — порт API, по умолчанию `3000`
- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather). Пока пустой, заявки работают, сообщения в Telegram не отправляются

После токена перезапустите API. Администратор или исполнитель открывает в приложении «Контакты» и переходит по ссылке «Подключить бота», затем в Telegram нажимает Start.

## Полезные команды

```bash
npm run start:dev    # разработка с перезапуском
npm run build        # сборка в dist
npm run start:prod   # запуск собранной версии
npm run db:migrate   # только миграции
npm run db:seed      # только тестовые пользователи
```

Импорт справочника из JSON удаляет все заявки и текущие наименования, пользователи остаются:

```bash
node scripts/import-products.mjs путь/к/products.json
```

В JSON — массив объектов `{ "title", "unit", "price" }`. Единицы: шт, кг, м³, л, м, м², упак, набор, т, компл, час, кор, поддон, лист. В базе уже должен быть администратор.
